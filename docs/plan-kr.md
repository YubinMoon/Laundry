# 세탁물 분류 및 빨래 추천 앱 프로젝트 계획서

> 본 문서는 프로젝트 초기 회의 및 사전 조사 결과를 바탕으로 작성한 기획 및 개발 계획서이다.

## 1. 프로젝트 개요

| 항목          | 내용                                                                          |
| ------------- | ----------------------------------------------------------------------------- |
| 팀명          | Team E                                                                        |
| 프로젝트 주제 | 세탁물 분류 및 빨래 추천 앱                                                   |
| 핵심 기술     | YOLO 기반 세탁물 형태 인식, 색상 추출 알고리즘, 사용자 보완 입력              |
| 주요 대상     | 자취 초보자, 빨래 경험이 적은 사용자, 세탁물 분류 기준이 익숙하지 않은 사용자 |

본 프로젝트는 사용자가 세탁물을 촬영하면 앱이 세탁물의 기본 형태와 색상을 분석하고, 사용자가 필요한 정보를 보완 입력하여 함께 세탁 가능한 묶음을 추천받을 수 있도록 하는 것을 목표로 한다.

단순히 사진 한 장으로 모든 세탁 정보를 자동 판단하는 방식이 아니라, 이미지 인식 모델과 후처리 알고리즘, 사용자 확인 과정을 결합하여 실제 사용 가능한 세탁물 관리 흐름을 설계한다.

## 2. 주제 선정 배경

초기 회의에서는 강의실 행동 인식, 지하철 혼잡도 감지, 수화 인식 키보드, 낙상 감지, 택배 감지, 거리 혼잡도 인식 등 여러 아이디어가 제안되었다. 이 중 최종 주제로 선정된 것은 세탁물 분류 및 빨래 추천 앱이다.

선정 배경은 다음과 같다.

- 자취 초보자나 빨래 경험이 적은 사용자는 옷의 종류, 재질, 색상에 따라 세탁물을 분류하는 과정에서 어려움을 겪는다.
- 분리 세탁 기준을 잘못 판단하면 의류 손상이나 이염이 발생할 수 있다.
- 사용자가 매번 세탁 기준을 직접 판단하지 않아도 되도록, 앱이 세탁물 정보를 축적하고 적절한 세탁 시기와 조합을 추천할 수 있다.
- 이미지 인식 모델을 활용한 실습 주제로 적합하며, YOLO Fine-tuning을 주요 기술 목표로 설정할 수 있다.

## 3. 프로젝트 목표

본 프로젝트의 최종 목표는 세탁물의 기본 형태와 색상 정보를 기반으로 세탁 가능한 그룹을 추천하는 모바일 앱을 개발하는 것이다.

이를 위해 다음 목표를 설정한다.

- YOLO 모델을 활용하여 세탁물의 기본 형태를 1차 분류한다.
- 탐지된 세탁물 영역을 기준으로 주요 색상을 추출한다.
- 자동 인식 결과를 사용자가 확인하고 수정할 수 있는 입력 과정을 제공한다.
- 등록된 세탁물 정보를 기반으로 함께 세탁 가능한 그룹을 자동 분류한다.
- 세탁물이 충분히 쌓이면 사용자에게 세탁 시기를 안내하는 흐름을 설계한다.

## 4. 사전 조사 결과

### 4.1 초기 구상

초기에는 사진 한 장으로 다음 정보를 모두 자동 인식하는 시스템을 구상하였다.

- 옷의 종류
- 옷의 재질
- 옷의 색상
- 세탁 가능 여부
- 함께 세탁 가능한 조합

그러나 사전 조사 결과, 단일 YOLO 모델만으로 위 정보를 모두 정확하게 판단하는 것은 현실적으로 어렵다고 판단하였다. 특히 재질과 세탁 가능 여부는 사진만으로 안정적으로 판단하기 어렵고, 색상 역시 조명과 그림자, 카메라 화질에 따라 결과가 달라질 수 있다.

### 4.2 YOLO 적용 한계

YOLO 모델을 그대로 사용할 경우 다음 한계가 있다.

- 기본 YOLO 모델에는 세탁물의 세부 종류나 재질을 구분할 수 있는 클래스가 부족하다.
- 옷이 바닥에 펼쳐져 있거나 구겨져 있는 경우, 일반적인 의류 데이터셋과 형태가 달라 인식 정확도가 낮아질 수 있다.
- 사진만으로 재질을 정확히 판단하기 어렵다.
- 색상은 촬영 환경의 영향을 크게 받기 때문에 YOLO만으로 처리하기 적합하지 않다.

따라서 YOLO는 모든 정보를 판단하는 모델이 아니라, 세탁물의 기본 형태를 인식하는 1차 분류 모델로 활용하는 것이 적절하다고 판단하였다.

## 5. 기술 방향

### 5.1 YOLO 기반 형태 인식

YOLO는 세탁물의 대략적인 형태를 분류하는 데 집중한다. 세부 의류 종류나 재질까지 완전히 판단하도록 설계하기보다, 사용자 입력을 보완할 수 있는 기본 형태 인식 단계로 활용한다.

예상 분류 대상은 다음과 같다.

- 상의
- 하의
- 수건
- 양말
- 기타 세탁물

### 5.2 색상 추출 알고리즘

색상 정보는 YOLO 모델이 아니라 별도의 후처리 알고리즘으로 추출한다. YOLO가 탐지한 세탁물 영역을 기준으로 주요 색상을 분석하고, 이를 세탁 분류에 활용 가능한 색상 계열로 정리한다.

예상 색상 분류 방향은 다음과 같다.

- 흰색 계열
- 어두운 색 계열
- 컬러 계열

### 5.3 사용자 보완 입력

자동 인식 결과는 항상 정확하다고 보기 어렵기 때문에, 사용자가 결과를 확인하고 수정할 수 있는 과정을 포함한다.

예시는 다음과 같다.

- YOLO가 하의로 인식한 경우, 사용자가 청바지, 면바지, 슬랙스 등 세부 타입을 선택한다.
- 색상 추출 결과가 부정확한 경우, 사용자가 색상 계열을 수정한다.
- 재질 판단이 필요한 경우, 사용자가 직접 재질 정보를 입력한다.

이 구조를 통해 모델의 한계를 보완하고, 실제 사용 가능한 앱 흐름을 구성한다.

## 6. 앱 동작 프로세스

앱의 전체 동작 과정은 다음과 같다.

```text
세탁물 배치
    ↓
카메라 촬영
    ↓
YOLO 기반 세탁물 형태 인식
    ↓
색상 추출 알고리즘 적용
    ↓
사용자 확인 및 세부 정보 입력
    ↓
DB 등록
    ↓
세탁 가능 그룹 자동 분류
    ↓
세탁 시기 알림
```

세부 과정은 다음과 같다.

1. 사용자가 세탁할 옷을 바닥에 펼쳐 놓는다.
2. 앱에서 카메라로 세탁물을 촬영한다.
3. YOLO 모델이 세탁물의 기본 형태를 인식한다.
4. 별도 알고리즘이 탐지된 영역의 색상 정보를 추출한다.
5. 사용자가 인식 결과를 확인하고 필요한 정보를 수정한다.
6. 세탁물 정보가 DB에 저장된다.
7. 앱은 함께 세탁 가능한 항목을 자동으로 그룹화한다.
8. 세탁물이 충분히 쌓이면 사용자에게 세탁 시기를 알린다.
9. 세탁이 완료된 항목은 기록에서 제외한다.

## 7. 데이터셋 및 학습 계획

초기 학습에는 DeepFashion2 Dataset을 활용하여 의류 형태 분류 가능성을 검토한다.

다만 프로젝트에 필요한 데이터는 일반 패션 이미지와 차이가 있다. 실제 사용 환경에서는 옷이 바닥에 놓여 있거나 구겨져 있을 가능성이 높기 때문이다. 따라서 기존 데이터셋만으로는 실제 사용 상황을 충분히 반영하기 어렵고, 프로젝트 목적에 맞는 추가 데이터 확보가 필요하다.

추가 확보가 필요한 데이터는 다음과 같다.

- 바닥에 펼쳐진 상의 이미지
- 바닥에 펼쳐진 하의 이미지
- 수건 이미지
- 양말 이미지
- 구겨진 세탁물 이미지
- 팀원이 직접 촬영한 테스트 이미지

부족한 클래스는 팀원이 직접 데이터를 수집하여 추가 학습에 활용한다.

## 8. 리스크 및 대응 방안

현재 가장 큰 리스크는 실제 세탁물 사진에서 YOLO 모델이 의류 형태를 충분히 구분하지 못할 가능성이다. 특히 바닥에 놓인 옷, 구겨진 옷, 수건과 양말처럼 일반 의류 데이터셋에서 충분히 다루지 않는 대상은 인식 성능이 낮을 수 있다.

대응 방안은 다음과 같다.

- 기존 데이터셋으로 빠르게 1차 모델을 학습한다.
- 직접 촬영한 사진으로 실물 테스트를 진행한다.
- 인식 가능한 클래스와 인식이 어려운 클래스를 구분한다.
- 수건, 양말 등 부족한 클래스는 직접 데이터셋을 추가한다.
- 핵심 기능 구현이 어렵다고 판단될 경우, 빠르게 다른 프로젝트 주제로 전환한다.

## 9. 기대 효과

본 프로젝트가 구현되면 사용자는 세탁물을 직접 하나씩 분류하지 않아도 앱을 통해 기본 세탁 정보를 정리할 수 있다. 또한 세탁 가능한 조합을 추천받음으로써 의류 손상과 이염 위험을 줄일 수 있다.

프로젝트 측면에서는 YOLO Fine-tuning, 이미지 후처리, 사용자 보완 입력, DB 기반 그룹 분류 흐름을 함께 다룰 수 있어 이미지 인식 모델을 실제 서비스 구조에 적용하는 경험을 얻을 수 있다.

## 10. 결론

세탁물 분류 및 빨래 추천 앱은 세탁물 분류의 불편함을 줄이기 위해 YOLO 기반 이미지 인식과 사용자 보완 입력을 결합한 프로젝트이다.

사전 조사 결과, 사진 한 장만으로 옷의 종류, 재질, 색상을 모두 완벽하게 자동 판단하는 것은 어렵다. 따라서 YOLO는 세탁물의 기본 형태 인식에 집중하고, 색상 추출은 별도 알고리즘으로 처리하며, 세부 정보는 사용자가 보완하는 구조로 설계한다.

향후에는 YOLO 실행 환경 구축, DeepFashion2 기반 1차 학습, 직접 촬영 이미지 테스트를 통해 프로젝트의 실현 가능성을 검증할 예정이다.
